Dateien auf die gesamte Chatfläche ziehen; zusätzliche Bildformate GIF/BMP/AVIF werden für den Chat in PNG umgewandelt. UTF-8-Textdateien werden auch bei unbekannter Dateiendung erkannt. Bestehende Größen- und Modellgrenzen gelten; PDF, Office, Archive und Binärprogramme werden nicht als Text ausgegeben.

Im Chat: „Updates“ prüft GitHub. Neue Veröffentlichungen erscheinen sichtbar als „Update verfügbar“, beim Start und alle 15 Minuten bei geöffneter App. Der Download und die Installation werden ausdrücklich gestartet.

Separates Admin-ZIP: bestehender Zugangscode und verschlüsselter Schutz bleiben erhalten. „Credits vergeben“ sucht Konten auf demselben Server und schreibt Credits einmalig, protokolliert und gegen doppelte Anfragen geschützt gut. „Update senden“ veröffentlicht eine fertige Setup.exe oder ZIP in stelexacc/New; benötigt einen eigenen GitHub-Token mit Contents-Schreibrecht. Token wird nicht gespeichert. Fehlgeschlagene Uploads bleiben unveröffentlichte Entwürfe.

Client-Setup installiert KEIN Admin-Panel. Desktop-Verknüpfung optional. DeepSeek, Free-Limits, Plugins und Python-/EXE-Ausgabe enthalten. Echte Python- und EXE-Erstellung wird unter Windows geprüft; fremder Quelltext wird nicht in Python oder EXE umbenannt. Vor dem Wechsel alte Client- und Admin-Apps schließen.
